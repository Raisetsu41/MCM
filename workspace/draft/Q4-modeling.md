# 问题四建模设计：多维数据采集建议（Q4-modeling）

> 状态：设计稿 v2（供论文"问题四"章节使用；正式入论文时删除本注释块）。
> 定位：2023-C 问题四为开放论述型问题，论文中不套用"模型建立/模型求解"结构，
> 按"数据清单 → 模型帮助 → 决策帮助 → 理由与可行性 → 优先级"组织。

## 一、问题定位与回答框架

**题面**：为了更好的制定蔬菜类商品的补货和定价决策，商场还需要采集哪些数据？
这些数据对建立数学模型和制定决策有什么帮助？请说明理由。

**回答原则**
1. 重心在"数据清单"：每类数据写清楚采集什么（字段、粒度、频率、来源系统）、
   帮助哪个模型的哪个参数、改善什么决策、为什么现在缺。
2. 每类数据统一五段式：采集内容 → 模型帮助（公式/参数映射）→ 决策帮助 →
   理由与可行性 → 偏误风险与验证。
3. 与前三问暴露的模型缺口一一对应，形成"数据—模型—决策"闭环：
   - Q1 缺真实购物篮 → 需要真实交易流水号；
   - Q2 需求预测缺外生变量 → 需要天气、节假日、促销日历；
   - Q2 批发价假设可观测 → 需要实时批发价与供应商报价；
   - Q3 单品需求假设相互独立 → 需要交叉弹性数据；
   - Q2/Q3 损耗率假设恒定 → 需要分环节损耗数据。
4. 每个新数据都给出"验证钩子"：加入前后用回测指标（RMSE、缺货率、利润）对比，
   证明其确有增益，衔接论文"模型检验"章。

## 二、总体框架：五个数据维度

沿用团队 `ANALYSIS_0.md` 的"需求/供给/运营/市场"分类口径，新增
"外部环境与营销事件"维度，共五维：

| 维度 | 采集重点 | 主要修补的模型缺口 |
|---|---|---|
| 3.1 需求侧 | 会员 ID、缺货登记、真实交易流水 | Q1 购物篮、Q2/Q3 需求预测低估 |
| 3.2 市场侧 | 竞品实时均价、陈列拓扑 | Q2 弹性校准、Q3 单品替代效应 |
| 3.3 运营侧 | 日内库存水位、打折流水、客流 | Q2/Q3 单周期假设、日内动态定价 |
| 3.4 供给侧 | 分环节损耗率、供应商履约 | Q2 恒定损耗率、提前期不确定性 |
| 3.5 外部环境与营销事件 | 天气、节假日、促销日历 | Q2 预测精度、基准需求 μ 与 σ |

## 三、分维度详述

### 3.1 需求侧：会员 ID、缺货登记与真实交易流水

**采集内容**
- 脱敏会员 ID（或家庭户标识）：POS 收银环节关联跨期交易流水，字段含会员 ID、
  交易流水号、下单时间、单品明细、金额；粒度：交易级；频率：实时/日结。
- 缺货登记日志：收银台/线上小程序记录"消费者搜索但未找到"的商品、时间、数量；
  频率：实时。
- 真实交易流水号：用于还原消费者真实购物篮；来源：POS/ERP。

**模型帮助**
- 真实流水号可精准还原购物篮，直接弥补 Q1 目前仅能用"去季节销量相关 + 聚类"
  近似关联关系的不足，升级为真实购物篮关联规则（Apriori/FP-Growth）或网络分析；
- 缺货登记修正被抑制的需求，单品真实需求为：
  $$D_{i,t}^{\text{true}} = D_{i,t}^{\text{sold}} + D_{i,t}^{\text{lost}} \tag{1}$$
  用 $D^{\text{true}}$ 重估 Q3 基准需求 $d_i$ 与 Q2 报童均值 $\mu_{c,t}$，
  避免仅依赖历史已售数据导致的系统性低估；
- 会员跨期购买行为可将"群体聚合幂律需求"升级为会员分层需求模型（RFM 分群 +
  价格敏感度分层，按层给出分层弹性需求），不做"千人千面"个体定价
  （个人定价不现实且有合规风险）。

**决策帮助**
- 补货量更贴近真实需求，降低缺货损失；按会员分层做差异化促销，
  兼顾利润与顾客留存。

**理由与可行性**
- 缺货登记近乎零成本（POS/小程序增加一个登记字段即可）；会员 ID 属中等改造成本，
  需做脱敏与隐私合规（《个人信息保护法》：最小化采集、匿名化、仅存聚合特征）。

**偏误风险与验证**
- 风险：缺货登记可能重复/误报（同一顾客多次登记、员工代登）、会员数据稀疏
  （低频顾客占多数）。
- 处理：按"会员+商品+时段"去重、设置最小登记量阈值；稀疏会员不做个体建模，
  仅聚合到分群。
- 验证钩子：用缺货登记修正前后的 $d_i$、$\mu_{c,t}$ 分别回测报童缺货率与利润，
  对比修正是否带来显著改善。

### 3.2 市场侧：竞品实时均价与陈列拓扑

**采集内容**
- 可比商圈内（如 2–3 km 或按步行可达范围，需在文中说明依据）农贸市场、生鲜电商、
  社区团购的同品类实时标价；粒度：品类/单品；频率：日采样（或每周 2–3 次）。
- 各蔬菜单品货架物理位置坐标，形成空间距离矩阵；来源：陈列巡检/电子价签。

**模型帮助**
- 竞品价格作为外生变量进入 Q2 需求—价格回归，校准品类弹性 $\beta_c$，
  避免"涨价即掉量"被误判为弹性过高；
- 用竞品比价与陈列邻近度构造交叉价格弹性矩阵，将 Q3 单品需求从独立函数升级为
  耦合函数：
  $$D_i(\mathbf{p}) = d_i \prod_{j}\left(\frac{p_j}{p_j^0}\right)^{\varepsilon_{ij}},\quad
  \varepsilon_{ii} = \hat{\beta}_i \tag{2}$$
  其中 $\varepsilon_{ij}$（$i\neq j$）为交叉价格弹性；当 $\varepsilon_{ij}=0$
  （$i\neq j$）时式 (2) 自动退化为 Q3 的独立需求
  $D_i(p_i)=d_i(p_i/p_i^0)^{\hat{\beta}_i}$，保证模型体系自洽；
- 交叉弹性矩阵可直接嵌入 Q3 MIP 目标函数，量化"小白菜涨价后消费者转向上海青"
  的替代效应，避免同类相食（Cannibalization）。

**决策帮助**
- 定价考虑外部比价与内部替代，联合定价避免内部利润自相蚕食；
- 陈列拓扑指导选品与货架布局，邻近替代品采用差异化定价。

**理由与可行性**
- 现有附件无竞品数据，弹性估计存在竞争环境混淆；竞品价格可通过人工抽样或
  公开平台采集，成本中等，建议中期落地。

**偏误风险与验证**
- 风险：竞品采样本底不一致（不同门店/渠道缺价）、价格可比口径差异
  （促销价 vs 挂牌价）。
- 处理：只对同口径价格建模、缺失用品类均值/上周值填充并打缺失标记。
- 验证钩子：加竞品变量前后回归 $R^2$ 与 AIC 对比；交叉弹性模型的选品利润
  vs 独立需求模型选品利润对比。

### 3.3 运营侧：日内库存水位、打折流水与客流

**采集内容**
- 借助电子秤联网/RFID（长期方案）采集日内分时段库存余量与鲜度评级
  （早/午/晚）；来源：称重系统、RFID。
- 黄昏清仓时段（如 19:00 后）的具体折扣率与对应销量；附件 2 已有"是否打折"标记，
  缺的是折扣率与时段，属低成本增量改造。
- 分时段客流量、客单价（可由收银小票聚合得到）；频率：小时级。

**模型帮助**
- 将 Q2/Q3 的"单周期日定价"升级为日内动态定价的随机控制模型（主模型仍是 Q2
  日定价与 Q3 日决策，日内 DP 是其补充层，不推翻主模型）：
  $$V_t(i_t, I_t, a_t) = \max_{p_t}\left\{ p_t \cdot \min(D_t(p_t), I_t) +
  \mathbb{E}\left[V_{t+1}(i_{t+1}, I_{t+1}, a_{t+1})\right]\right\} \tag{3}$$
  其中 $I_t$ 为剩余库存、$a_t$ 为鲜度状态（随时间衰减）、$i_t$ 为时间阶段，
  终端条件为末期未售部分按损耗清零；
- 动态定价输出的"预期日内折扣损失"作为修正项回传报童临界比 $\kappa_{c,t}$，
  避免过度乐观定价导致晚间积压损耗；
- 分时段客流作为外生变量提升日内需求估计精度。

**决策帮助**
- 给出每日最优清仓时点与折扣梯度，平衡"晚间低价清货"与"利润损失"；
- 补货量在临界比层面已预扣日内折价损失，减少期末报废。

**理由与可行性**
- 打折流水为低成本增量改造（补折扣率与时段字段即可）；RFID/电子秤联网成本较高，
  作为长期可选项，文中需注明。

**偏误风险与验证**
- 风险：时段库存测量噪声、鲜度评级主观、清仓折扣与正常售价混记。
- 处理：鲜度评级用统一标准（外观/剩余可售时长打分），折扣单单独标记。
- 验证钩子：日内 DP 的期末损耗率与固定日定价回测对比；临界比修正前后的
  缺货率/报废率对比。

### 3.4 供给侧：分环节损耗率与供应商履约数据

**采集内容**
- 按"运输 → 入库 → 上架 → 清仓"四个节点分段记录实际损耗量；
  来源：门店交接单/配送单；频率：每批次。
- 各供应商历史到货提前期（LTD）、批次合格率、履约准时率；
  来源：供应商对接/ERP；频率：每批次。
- 每日实时进货价与供应商报价（含波动区间）；来源：采购系统；频率：日。

**模型帮助**
- 附件 4 目前只提供"综合损耗率"，分环节数据可将常数 $L_i$ 升级为时变损耗函数
  （如指数衰减 $L(t) = 1 - e^{-\kappa t}$ 或分段线性插值），刻画损耗随储存时间
  加速增长的真实过程，$\kappa$ 由分环节历史数据拟合：
  $$L(t) = 1 - e^{-\kappa t} \tag{4}$$
- 补货公式升级为（报童模型的扩展，主模型不变）：
  $$R_{c,t} = \frac{\mu_{c,t}(P^*) + \Phi^{-1}(\kappa_{c,t})\cdot\sigma_{c,t}}
  {1 - \bar{L}_{c,t}} \tag{5}$$
  其中 $\bar{L}_{c,t}$ 为按到货批次品质动态调整的预期综合损耗率；
- 提前期不确定性引入安全库存项（需求率 $\mu_d$、提前期标准差 $\sigma_L$）：
  $$\text{SS} = z \cdot \sqrt{\sigma_d^2 \cdot L + \mu_d^2 \cdot \sigma_L^2} \tag{6}$$
- 实时批发价可将"未来一周批发价取最近均价"的假设升级为价格情景区间
  （如 ARIMA 预测 + 置信区间），支撑灵敏度分析。

**决策帮助**
- 补货量同时反映"到货批次品质差异"与"上架后随时间衰减"，降低缺货与报废；
- 供应商履约指数可指导供应商选择与订货量分配，提升供应链韧性。

**理由与可行性**
- 分环节损耗需门店交接单改造，成本中低，建议短期优先；
- 供应商履约数据需与供货方对接，属中期项。

**偏误风险与验证**
- 风险：环节归属不清（损耗发生在哪个环节难判定）、提前期样本少。
- 处理：交接单逐节点签字确认损耗责任；提前期至少收集 10 个批次再启用式 (6)。
- 验证钩子：时变损耗 vs 恒定损耗的期末损耗率回测对比；含/不含提前期安全库存
  的缺货率对比。

### 3.5 外部环境与营销事件：天气、节假日与促销日历

**采集内容**
- 日/小时级天气数据（温度、降雨量、湿度），来源为第三方天气 API 或气象站，
  含 1 天滞后项与极端天气哑变量（暴雨、台风、高温预警）；
- 节假日、节气、周末与大型活动日历（如春节、五一、国庆、台风预警），公开日历；
- 商超自身促销活动计划（促销品类、折扣力度、起止时间），来源：运营排期表。

**模型帮助**
- 天气与节假日是蔬菜需求最强的外生驱动（4–10 月供给丰富、极端天气推高叶菜需求），
  直接进入 Q2 需求—价格回归与 Prophet 预测，作为外生回归项：
  $$\ln Q_{c,t} = \alpha_c + \beta_c \ln P_{c,t} +
  \sum_k \delta_k \mathbb{1}_{\text{weekday}=k} +
  \sum_m \eta_m \mathbb{1}_{\text{month}=m} +
  \gamma_T T_{c,t} + \gamma_R \text{Rain}_{c,t} +
  \theta_1 \text{Holiday}_t + \theta_2 \text{Promo}_t + \varepsilon_{c,t} \tag{7}$$
- 提升基准需求 $\bar{Q}_{c,t}$ 与残差标准差 $\sigma_{c,t}$ 的估计精度，
  进而改善报童补货量的均值—方差结构。

**决策帮助**
- 预测期若遇极端天气或节假日，自动上调补货量与价格保护区间；
- 促销日历与定价联动，避免促销期与非促销期需求混淆导致弹性误估。

**理由与可行性**
- 成本极低（公开 API + 内部日历），见效最快，建议最高优先级。

**偏误风险与验证**
- 风险：天气数据粒度（气象站点 vs 门店位置）不一致、促销与需求互为因果
  （促销导致销量上升而非需求上升）。
- 处理：用门店最近气象站数据并说明距离；促销变量只用于"去混淆"，
  弹性估计以非促销样本为主或加入促销交互项。
- 验证钩子：加天气/促销变量前后 Prophet 回测 RMSE 与 MAE 对比
  （训练期后滚动预测 7 天）。

## 六、ROI 论证与"最优先三件事"

**ROI 论证**：采集价值可量化为"决策增益 − 采集成本"，以本文前三问的利润量级为基准：
- 缺货率每降 1 个百分点、期末报废率每降 1 个百分点，对周毛利的影响可由
  Q2/Q3 补货模型直接测算；
- P1 类数据（缺货登记、天气、促销日历、分环节损耗）总改造成本为千元级，
  而预期缺货/报废率下降带来的周毛利提升通常远高于该成本，短期投入回报为正；
- 论文中可用 Q2 回测结果给出"每降低 1% 缺货率 ≈ 毛利提升 X%"的量化语句
  （数据落地后填入实测值）。

**最优先三件事**：先做 ① 缺货登记日志、② 天气/节假日数据接入、
③ 促销计划与力度表。三者成本最低、见效最快，分别直击需求低估、
预测精度、弹性去混淆三大模型缺口。
