\section{模型的评价、改进与推广}

\subsection{模型的优点}

\begin{itemize}
  \item \textbf{问题一的四层递进框架完整刻画了需求结构。} 本文从“分布形态—季节规律—关联网络—需求聚类”四个层次逐层深入，品类日销量分布与单品混合分布模型、STL季节分解、去季节相关网络与Ward聚类层层递进、互为支撑：分布模型为报童补货提供输入，季节模型为定价节奏提供约束，关联网络为单品选品提供候选组合，聚类结果为差异化定价提供分组依据。四部分结论分别对应后续三个问题的核心输入，模型体系完整、逻辑链条清晰。

  \item \textbf{问题二的定价—补货联合优化在理论上自洽、在操作上可行。} 在乘性需求假设下，本文证明了顺序决策（先定价、后补货）等价于联合优化，将复杂的定价—库存联合问题分解为可独立求解的两步。最优加价率仅依赖品类弹性与损耗率、与批发价无关，直接回应了题面“凌晨3:00–4:00不知具体进货价”的时序约束，使商超可提前制定加价策略、到货后按实际批发价套用售价。此外，本文严格论证了在无跨品类约束、风险中性的条件下，品类间相关性仅影响总利润方差而不影响期望利润，逐品类独立优化与整体联合优化等价，为问题二采用品类独立优化提供了理论支撑。

  \item \textbf{问题三的MIP联合优化有效处理了单品级耦合约束。} 针对单品级数据稀疏、弹性不可识别的困难，本文采用经验贝叶斯收缩将单品弹性向品类弹性靠拢，稳定了需求函数的估计；将连续定价离散化为价格网格，使非线性利润目标转化为线性MIP，在27–33个选品数与2.5kg最小陈列量的双重约束下实现全局最优求解，避免了启发式算法无法保证最优性的风险。

  \item \textbf{四类灵敏度分析系统验证了模型的稳健性。} 本文对缺货惩罚、选品数、弹性、批发价、损耗率、价格网格与大M取值等关键参数逐一进行了扰动分析，批发价±10\%扰动下的利润变化范围（-17.6\%/+18.1\%）被量化识别，其他扰动下结论保持稳定。求解状态全部为optimal、最优性gap=0，约束校验全部通过，且与问题二品类级计划的交叉核对量级一致，模型结论的可靠性有充分证据支撑。

  \item \textbf{问题四的数据需求分析紧密咬合前序模型的具体公式。} 每类数据建议均指向前序模型中的特定参数或特定公式（如$P_{c,t}^{\text{obs}}$的价格口径偏误、$d_i$的需求截断低估、$L_i$的损耗恒定假设），并给出了采集后的具体升级路径。四类数据之间的协同效应（折扣标记与缺货登记结合可完整识别需求曲线两端、购物篮关联与货架距离结合可校准替代弹性的空间衰减、分时段库存与分环节损耗率结合可为日内动态定价提供准确的状态转移约束）进一步增强了方案的系统性。
\end{itemize}


\subsection{模型的缺点}

\begin{itemize}
  \item \textbf{单品需求独立假设与蔬菜零售现实存在差距。} 问题三的MIP模型假设$D_i(p_i)$不含其他单品价格，忽略了“白菜涨价→消费者转向上海青”的替代效应以及外部竞品降价的客源分流。在问题一识别出部分品类存在正相关的条件下，独立需求模型可能高估协同品类的综合利润。这一问题在问题四中已作为数据扩展方向明确提出（市场侧——陈列拓扑图与竞品实时均价），但其引入将显著增加MIP的变量规模与求解难度。

  \item \textbf{单周期日清模型未覆盖日内动态定价与清仓。} 问题二、三均假设当日未售罄部分全额损耗、无日内打折清仓。实际生鲜商超在每日下午至傍晚（如19:00后）会对品相变差的商品打折出售，这一行为既影响当日实际利润，也改变了“未售罄残值为零”的报童假设基础。日内动态定价的引入需要小时级库存水位与打折流水数据，留待问题四扩展。

  \item \textbf{缺货日需求截断导致补货量系统性低估。} 问题三的基准需求$d_i$基于6/24–30已售净销量，若某单品在该窗口内缺货，真实需求$D_{i,t}^* = Q_{i,t} + U_{i,t}$（$U_{i,t}\ge0$）中的$U_{i,t}$完全不可观测，$d_i$系统性偏低，报童补货量随之偏小。该问题需缺货登记数据修正，已在问题四采集方案二中给出具体公式$D_{i,t}^* = Q_{i,t} + \alpha_i m_{i,t} + \varepsilon_{i,t}$与修正路径$d_i^* = (1/T_{\text{win}})\sum_{t\in\text{win}}[Q_{i,t} + \alpha_i m_{i,t}]$。

  \item \textbf{有限样本下部分参数的估计精度不足。} 问题二中水生根茎类的价格弹性$\hat\beta_c=-0.07$不显著（$t=-0.70$），其定价结论证据不足；问题三中45个候选单品有13个原始弹性为正，其中12个最终借用品类弹性，说明单品层面的价格信号识别存在困难。虽然Shrinkage估计在统计上是处理稀疏数据的标准做法，但借用品类弹性意味着单品间差异化定价的信息来源单一。
\end{itemize}


\subsection{模型的改进}

\begin{itemize}
  \item \textbf{将单品需求从独立假设升级为含交叉价格弹性的耦合需求。} 当前MIP模型的核心局限是$D_i(p_i)$不含$p_j$（$j\ne i$）。改进方向为：引入问题四中的货架距离$\text{dist}_{ij}$与竞品价格$P_{i,t}^{\text{comp}}$，将需求函数扩展为$D_i(p_i,\mathbf{p}_{-i})=d_i(p_i/p_i^0)^{\beta_i}\prod_{j\ne i}(p_j/p_j^0)^{\epsilon_{ij}}$，其中$\epsilon_{ij}=\epsilon_{ij}^0\exp(-\lambda\cdot\text{dist}_{ij})$。该升级将使MIP目标函数中的需求项从单变量$D_{i,k}$变为多变量耦合函数，求解难度将从线性MIP上升为二次或非线性MIP，需采用更高效的求解器（如Gurobi）或启发式算法近似求解。

  \item \textbf{将日清确定性模型扩展为日内动态定价与随机库存控制。} 当前报童模型假设每日单次定价、无日内调整。改进方向为：引入问题四中的分时段库存$I_{i,t,\tau}$与品相等级$g_\tau$，建立贝尔曼方程$V_\tau(I_\tau,g_\tau)=\max_{\delta_\tau}\{\mathbb{E}[p(\delta_\tau)\min(D_\tau(p),I_\tau)+V_{\tau+1}(I_\tau-\min(D_\tau,I_\tau),g_{\tau+1})]\}$，将日清报童模型扩展为多时段动态规划模型。该模型需要小时级需求预测（含客流与鲜度衰减）作为输入，可在现有日粒度数据基础上逐步实施。

  \item \textbf{以缺货登记数据修正需求截断偏误。} 改进方向为：在收银台或线上小程序设置缺货登记入口，采集$m_{i,t}$后按$d_i^*=(1/T_{\text{win}})\sum_{t\in\text{win}}[Q_{i,t}+\alpha_i m_{i,t}]$修正基准需求，替代当前基于已售净销量$d_i=(1/T_{\text{win}})\sum_{t\in\text{win}}Q_{i,t}$的口径。该改进需解决缺货登记率$\alpha_i$的校准问题（可通过小规模抽样或同类单品对比估计），但能够从根本上解决“缺货日需求被截断”这一模型系统偏差。

  \item \textbf{将预测窗口从7天扩展为滚动优化。} 当前问题二、三均为单次预测—决策（7月1–7日）。改进方向为：每日更新数据、重新预测与求解，即滚动时域优化（Rolling Horizon Optimization）。该框架可以在7月1日预测7月1–7日、在7月2日根据7月1日实际销售数据更新预测并重新优化7月2–8日，持续滚动执行。滚动优化能够吸收实际销售与预测之间的偏差，增强模型对需求不确定性的适应能力，但其计算成本将线性增加。
\end{itemize}


\subsection{模型的推广}

本文所建立的“分布拟合—弹性估计—报童补货—MIP选品”四层建模框架不仅适用于蔬菜类商品的补货与定价决策，在以下场景中同样具有推广价值：

\begin{itemize}
  \item \textbf{其他生鲜品类（水果、肉禽、水产）。} 水果、肉禽、水产同样具有保鲜期短、品相随销售时间衰减、当日未售罄部分次日无法再售的特征。本文的核心模型（报童补货、成本加成定价、MIP选品）在品类结构上不依赖于蔬菜的特定属性，仅需调整损耗率参数与价格弹性估计即可迁移。零售商的货架空间限制与单品数约束（问题三的27–33个）在上述品类中同样存在，MIP框架可直接复用。

  \item \textbf{短保食品与烘焙类商品。} 面包、蛋糕、熟食等短保食品同样面临当日未售罄需报废的问题，且保质期通常为1–2天，比蔬菜的“一日清”略宽松，但数学结构相同。本文的报童模型与缺货惩罚机制可直接应用；与蔬菜不同的是，短保食品的需求受品牌与季节性影响更大，需求预测部分可增加品牌偏好变量与节日效应变量。

  \item \textbf{服装、电子产品等具有明显季末清仓特征的行业。} 虽然服装与电子产品的销售周期以“季”或“代”为单位而非“日”，但其核心矛盾一致：在有限销售窗口内决策订货量与价格，销售期末未售出商品需折价清仓。本文的定价—补货联合优化框架与MIP选品模型可迁移至季末清仓场景，区别在于销售周期由“日”拉长至“周”或“月”，需求分布的方差更大、季节性更强。

  \item \textbf{分布式零售网络的区域定价与库存调配。} 本文的模型针对单门店单品类决策，但同一商超品牌往往拥有多家门店，各门店面临不同的客流与竞争环境。将本文的品类弹性回归与报童补货模型嵌入分布式库存优化框架，可实现“中央预测—门店决策—区域调配”的三级供应链优化；问题四中提出的竞品均价（市场侧）与供应商履约指数（供给侧）在多门店场景下的信息价值将进一步提升。
\end{itemize}
